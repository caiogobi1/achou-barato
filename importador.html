Preparar catálogo do Buscoubarato

Ferramenta local para transformar uma lista de produtos em products.json. Nada é enviado para servidores. Não conecte credenciais do Mercado Livre aqui.

Cole uma linha por produto, separando as colunas com TAB (copiar e colar de uma planilha). Primeira linha: name cat store url image price oldPrice priceDate affiliate. Os campos image, price, oldPrice e priceDate são opcionais. Use apenas links de afiliado que você obteve oficialmente.

Para novos anúncios, informe affiliate_url obtido no programa de afiliados. O ID MLB permite reconhecer produtos repetidos; links de comissão existentes são preservados.

Este arquivo não publica produtos sozinho. Para manter o catálogo anterior, selecione o products.json atual no campo acima antes de gerar o novo arquivo. Depois de baixar, envie products.json para a raiz do repositório caiogobi1/achou-barato. O site já lê esse arquivo. Não inclua preços ou fotos não verificados.
