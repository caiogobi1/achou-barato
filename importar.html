Importação em lote — Buscou Barato

Cole linhas CSV com cabeçalho: nome,categoria,loja,preco,preco_antigo,imagem,link_afiliado. Para valores com vírgulas, use aspas, como "22,00". O link de afiliado deve ser obtido oficialmente. Não coloque senhas ou tokens aqui.

Exemplo:

nome,categoria,loja,preco,preco_antigo,imagem,link_afiliado
Jogo de potes,Casa,Mercado Livre,"22,00","43,90",,https://meli.la/18p9aCk

Como publicar

Depois de baixar, abra o repositório do site no GitHub, use Add file → Upload files e envie products.json para a raiz, substituindo o arquivo anterior quando necessário. O site lerá esse catálogo automaticamente após a publicação.
